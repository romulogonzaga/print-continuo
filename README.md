# Print Contínuo — Política de Privacidade

Página pública com a política de privacidade da extensão **Print Contínuo**.

## Conteúdo deste repositório

Este repositório contém a página institucional da política, em `index.html`. O código da extensão e seu instalador não estão incluídos aqui.

A política descreve o processamento das capturas no navegador, o armazenamento local de preferências e as informações de contato do desenvolvedor.

## Visualizar localmente

1. Clone ou baixe o repositório.
2. Abra `index.html` no navegador.

## Tecnologias

HTML e CSS, sem dependências externas ou etapa de compilação.

## Atualizar a política

Edite `index.html`, mantenha a data de atualização coerente com a revisão e confira o conteúdo no navegador.
