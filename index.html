Política de Privacidade — Print Contínuo

Última atualização: 1 de setembro de 2026

A extensão Print Contínuo não coleta, armazena nem transmite qualquer dado pessoal.

Dados acessados

Para funcionar, a extensão lê o conteúdo visual da aba que o usuário escolhe capturar. Esse conteúdo é processado inteiramente dentro do navegador do usuário e salvo como arquivo no computador dele. Nada é enviado a servidores do desenvolvedor ou a terceiros.

Preferências

As configurações escolhidas pelo usuário (formato, resolução, intervalo entre capturas) são guardadas localmente no navegador, através da API de armazenamento do Chrome. Não são sincronizadas nem compartilhadas.

Terceiros

A extensão não utiliza serviços de análise, publicidade ou rastreamento, e não faz conexões de rede.
